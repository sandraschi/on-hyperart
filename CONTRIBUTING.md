# Contributing — on-hyperart

## System of record

GitHub Issues (like the sister repos). Discord/forum threads are front-end
only and must be mirrored into the relevant Issue before counting as resolved.

## Rule 1 — Observability (per claim)

Name the chapter/section, what's wrong with its current evidence or wording,
and the concrete change. Every production-collapse claim must resolve to a
dateable, checkable public fact: release with date, model card, box-office /
streaming record, statute (ELVIS Act, AB 1836/2602 — verify number before
citing), union contract, manufacturer datasheet, dated press statement.
Quoted public speech for intentions. Private pipelines do not exist for this
book until publicly evidenced.

## Rule 2 — Hazard (HARD, non-negotiable)

This book describes control over culture. It must never facilitate abuse.

**In scope:** institutional facts (who shipped what, when, under whose
authority), governance criteria (publicity regimes, labor gates, watermark
standards, exhibition rules), control failures with dates.

**Out of scope, always cut on sight:** voice/likeness clone guides targeting
a named living person, filter- or watermark-defeat detail, procurement how-tos
for abuse pipelines, CSAM-adjacent description, code/configurations that
defeat a named protection. Attention hazards (grief-porn framing, shock
scoreboards) need explicit sign-off like in any other hazard call.

When in doubt, ask: does this paragraph help a principal attach a brake,
or help an operator press an accelerator? Ship only the first.

## Prose (trilogy house style + hyperart precision)

Beats first (3-5 facts per section), ugly draft, 3 AI variants constrained
to the README voice, red-team for flab, read aloud (declaim pipeline),
lore-keep chapter numbers and dates. No single-pass AI chapters. Attribute
with `Co-Authored-By:` trailers where model lines survive.

Analytical coldness: treat culture, cinema, voice, painting as technological
artifacts and information channels. Never mourn displacement; dissect the
economic and physical mechanisms that made it inevitable.

Technical precision (hard gate): not "animation" generically — sakuga,
impact frames, Kanada smears, cel-count constraints, spatial distortion.
Not "good sound" — formants, subharmonic split-tones, glottal fry, acoustic
compression, mucosal micro-tremors. An Opus/Gemini draft that stays generic
goes back for a domain pass.

No neoclassical humanism: "soul" and "lived experience" are non-falsifiable
rhetorical evasions unless cashed out as structural cues (information density,
harmonic shift, pacing, symbolic dissonance) that can be cataloged and
executed. Prove the trigger, don't assert the mystique.

## Definitions

- `[construction]` = asserted, not yet evidenced. Required flag, never silent.
- Thresholds A-E = attachment points with named owners (see Ch VI stub).
- No evidence-by-proximity: a demo reel is not a shipped pipeline.
- Fleet link: each chapter closes with one paragraph tying its collapse step
  to the parallel step in on-hyperwar / on-ai-takeover (same math, other domain).
