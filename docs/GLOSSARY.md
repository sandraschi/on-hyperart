# Glossary — on-hyperart

House rule (from sisters): add an entry here before using a new unglossed
term in a chapter.

**Compromise envelope** — historic iron triangle: narrative depth vs visual
velocity vs scale. Ch IV. Liquidated at zero marginal cost.

**Deniable archetype** — latent-space face/voice between established icons
(e.g. granite jaw + glottal anxiety) with zero liability. Ch VI/VIII + side.

**Folk-art demotion** — biological art respected for limitation, dwarfed in
density/power. Calligraphy precedent. Ch IX.

**Itano circus** — missile-swarm animation choreography (Macross). Ch VIII;
use for kinetic-dimension claims only with dated artifact.

**Kanada smear / impact frame** — limited-animation distortion techniques.
Ch IV/VIII; never generic "animation".

**Last Take / Frame / Face / Cut / Venue** — Thresholds A-E. Defined in
[chapters/06-thresholds.md](../chapters/06-thresholds.md); listed here only
as index.

**Orthogonal hypercinema** — maxing all dials at once: Nobel-density script
+ sakuga kinetics + 72-hour run. Ch VIII.

**Sakuga** — peak-intensity animated craft (animator-credited cuts). Ch IV/V.

**Verifier clock** — the domain's test latency sets its collapse speed.
Type checker: ms. Kinetics: ms. Simulator: minutes. Audience: hours at
population scale. Organism: years. Art fell first because its verifier is a
mammal who answers surveys. Side-hypermath; wired into Ch I.

**Validated novelty** — growth in the reachable set of consequences under a
checker, as opposed to free Shannon information. The honest form of the
"verified recombination" argument. Side-hypermath.

**World-alienation** — Arendt's objection, via Lepore: a world made entirely
by machines leaves humans encountering only themselves in disguise. The
strongest counter-thesis the book faces. Side-lepore-counter-thesis.

**Warning-as-recipe** — the corpus cannot distinguish a cautionary tale from
an instruction manual; the loss function has no column for *against*.
Ch II (Lepore ch. 12).
